# Data Dictionary

This document outlines the schema of the analytical datasets used in the final Power BI dashboard and Python analysis. 
The raw staging tables are based on the Olist Brazilian E-Commerce dataset.

## 1. analytical_orders

Target Grain: 1 Row = 1 Order

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `order_id` | VARCHAR | Unique identifier for the order. |
| `customer_id` | VARCHAR | Order-specific customer identifier (changes per order). |
| `customer_unique_id` | VARCHAR | Unique identifier for the customer (consistent across multiple orders). |
| `customer_state` | VARCHAR | Customer's state code (e.g., SP, RJ). |
| `customer_city` | VARCHAR | Customer's city name. |
| `order_status` | VARCHAR | Status of the order (e.g., delivered, shipped, canceled). |
| `order_purchase_timestamp` | DATETIME | Timestamp when the purchase was made. |
| `order_approved_at` | DATETIME | Timestamp when payment was approved. |
| `order_delivered_carrier_date` | DATETIME | Timestamp when the order was handed to the logistics partner. |
| `order_delivered_customer_date` | DATETIME | Timestamp when the order was delivered to the customer. |
| `order_estimated_delivery_date` | DATETIME | Estimated delivery date provided to the customer. |
| `items_value` | DECIMAL | Total value of products in the order. |
| `freight_value` | DECIMAL | Total shipping costs for the order. |
| `order_value_calculated` | DECIMAL | Sum of items_value and freight_value. |
| `payment_value` | DECIMAL | Actual amount paid by the customer (Primary Revenue Metric). |
| `items_qty` | INT | Total number of items in the order. |
| `review_score` | INT | Customer satisfaction score (1 to 5). |

## 2. analytical_customers

Target Grain: 1 Row = 1 Unique Customer

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `customer_unique_id` | VARCHAR | Unique identifier for the customer. |
| `first_order_date` | DATETIME | Timestamp of the customer's first purchase. |
| `last_order_date` | DATETIME | Timestamp of the customer's most recent purchase. |
| `order_count` | INT | Total number of valid orders placed by the customer. |
| `total_revenue` | DECIMAL | Total lifetime value (revenue) generated by the customer. |
| `average_order_value` | DECIMAL | Average value of the customer's orders. |
| `is_repeat_customer` | INT | Boolean flag (1/0) indicating if the customer has > 1 order. |

## 3. funnel_counts (Intermediate View)

Target Grain: Aggregated counts for funnel stages

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `funnel_stage` | VARCHAR | Name of the stage (Purchased, Approved, Shipped, Delivered, Reviewed). |
| `orders` | INT | Total number of orders reaching that specific stage. |
